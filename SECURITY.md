# Security

If you believe you have found a vulnerability in Antibody, **do not open a public issue**.

Please report it privately using GitHub's private vulnerability reporting on this repository:

https://github.com/r3dbars/antibody/security/advisories/new

Include enough detail to reproduce the problem (affected version, command, and a minimal fixture if you can share one). We will acknowledge the report and work on a fix before any public disclosure.

For non-security bugs and feature requests, use the public issue tracker.
