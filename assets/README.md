Visual rule: show the real product first. Use a diagram only when it explains
one concept more clearly than prose, terminal output, or native Markdown.

Palette: ink `#0D1117`, line `#30363D`, paper `#F0F3F6`, muted `#9DA7B3`,
signal `#F05A28`.
